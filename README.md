# NetCore Pro — فروشگاه B2B تجهیزات شبکه

## مرور پروژه

- **نام**: NetCore Pro
- **هدف**: فروشگاه آنلاین B2B تخصصی تجهیزات شبکه (سوییچ، روتر، فایروال، اکسس‌پوینت)
- **استک**: Hono + Node.js 20 + MySQL/MariaDB (SSR کامل، بدون React/Next)
- **ویژگی کلیدی**: **کاملاً مستقل از اینترنت بین‌المللی** — تمام asset ها داخل پروژه
- **تم بصری**: بازطراحی‌شده مطابق ویدیو مرجع — **تم روشن یکدست** (بنفش `#5b3fd6` + قرمز/صورتی `#ef2d56` روی پس‌زمینه `#f4f5fb`)، کاملاً ریسپانسیو با رفتار وب‌اپلیکیشن روی موبایل (هدر موبایل، drawer، bottom-nav)

### API
- `GET /api/health`
- `POST /api/auth/login` `/register`
- `GET /api/products?page=&limit=&category=&search=` — لیست عمومی (فقط محصولات فعال)
- `GET /api/products/featured` — محصولات منتخب (صفحه اصلی)
- `GET /api/products/categories` `/api/products/brands` — دسته/برند عمومی
- `GET /api/products/:slug` — جزئیات محصول
- `POST/PUT/DELETE /api/products[/:id]` — CRUD محصول (ادمین)
- `GET /api/blog/posts` `/api/blog/posts/:slug` — بلاگ عمومی (فقط منتشرشده)
- `GET/POST/PUT/DELETE /api/blog/admin/posts[/:id]` — CRUD مقاله (ادمین)
- `GET/POST/PUT/DELETE /api/admin/categories[/:id]` — CRUD دسته (با فیلد image) 🆕
- `GET/POST/PUT/DELETE /api/admin/brands[/:id]` — CRUD برند (با فیلد logo) 🆕
- **`POST /api/admin/upload`** 🆕 — آپلود تصویر (multipart `file` یا base64 `data`)؛ خروجی `{url}`
- **`GET /api/admin/uploads`** 🆕 — کتابخانه رسانه (فهرست تصاویر آپلودشده)
- `GET /api/content/blocks?page=&section=` — بلوک‌های محتوا (عمومی)
- `GET /api/content/pages?page=&section=` — صفحات محتوا (عمومی)
- `GET/POST/PUT/DELETE /api/content/admin/blocks[/:id]` — CRUD (نیاز به JWT ادمین)
- `GET/POST/PUT/DELETE /api/content/admin/pages[/:id]` — CRUD ادمین

## معماری داده

- **پیش‌فرض**: MySQL/MariaDB (تنظیم با متغیرهای `MYSQL_*` در `.env`)
- **گزینه جایگزین**: SQLite فایلی در `data/netcorepro.db` با `DB_TYPE=sqlite` (نسخه قدیمی/توسعه محلی)
- **مهاجرت داده**: اسکریپت `scripts/migrate-sqlite-to-mysql.mjs` داده SQLite را بدون تغییر به MySQL منتقل می‌کند

### جداول کلیدی
- `users`, `products`, `categories`, `brands`, `orders`, `order_items`
- `posts`, `comments`, `tickets`, `ticket_messages`
- `messages`, `newsletter_subscribers`, `settings`, `activity_logs`
- **`site_blocks`** — 🆕 بلوک‌های CRUD-able صفحات. ستون `image` برای عکس اسلایدر/بنرها. بخش‌های ویرایش‌پذیر صفحه اصلی:
  - `page='home', section='hero'` — اسلایدر اصلی (`icon`=متن دکمه، `image`=عکس، `description`=زیرعنوان، `href`=لینک)
  - `page='home', section='side_banner'` — بنرهای کناری (`icon`=کلاس FontAwesome مثل `fa-ethernet`)
  - `page='home', section='mid_banner'` — بنرهای میانی (`icon`=متن دکمه)
- **`site_pages`** — 🆕 محتوای صفحات استاتیک

## تست و کیفیت (آخرین اجرا — باگ‌گیری چنددوره‌ای کامل، دور ۸)

**۱۷ مجموعه تست خودکار** در پروژه موجود است (`scripts/`) — مجموعاً **۶۳۲ تست، ۰ شکست**. با یک دستور قابل اجرا:

```bash
node scripts/run_all.mjs      # همه ۲۰ مجموعه را پشت‌سرهم اجرا می‌کند (با فاصله ضدّ rate-limit)
```

> 🆕 در دور ۱۱، ۱ باگ امنیتی واقعی (با دو نقطهٔ نشت) کشف و رفع شد: (۲۸) تزریق تنظیمات ادمین بدون escape در HTML — لینک تلگرام در تاپ‌بار (روی همهٔ صفحات) و اطلاعات تماس (تلفن/موبایل/ایمیل/آدرس) در صفحهٔ «تماس با ما»؛ مقداری مثل `"><img src=x onerror=..>` از صفت/متن می‌شکست و به‌عنوان **XSS ذخیره‌شده** اجرا می‌شد. مجموعهٔ جدید `test_roundtrip10` (۱۱ تست) اضافه شد.
> 🆕 در دور ۱۰، ۱ باگ امنیتی واقعی کشف و رفع شد: (۲۷) دور زدن پاک‌سازی HTML (`sanitizeHtml`) با جداکنندهٔ اسلش — الگوی `<img/src=x/onerror=alert()>` که مرورگر آن را مثل صفت‌های جداشده با فاصله تفسیر می‌کند، از فیلترِ رویدادگرِ متکی به فاصله عبور می‌کرد و به‌عنوان **XSS ذخیره‌شده** در محتوای مقاله/توضیحات محصول اجرا می‌شد. مجموعهٔ جدید `test_roundtrip9` (۲۳ تست) اضافه شد.
