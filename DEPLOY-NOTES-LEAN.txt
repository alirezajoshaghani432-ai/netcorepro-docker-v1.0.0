راهنمای نصب نسخه سبک — رادیس (1405/09/05)
================================================
این بسته همه چیز سایت را دارد؛ چند بخش حذف شده چون به‌طور خودکار بازسازی می‌شوند:

1) node_modules حذف شده → بعد از باز کردن zip یک بار اجرا کنید:
       npm install
   ماژول native بهتر-اسکیولایت آماده است در: local_packages/better-sqlite3.tgz
       (اگر npm install از اینترنت نمی‌شد: npm install ./local_packages/better-sqlite3.tgz)

2) public/static/uploads حذف شده → سرور هنگام بوت خودش ./uploads را داخلش کپی می‌کند
   و مسیر /static/uploads/* هم به ./uploads برمی‌گردد. هیچ کاری لازم نیست.

3) public/static/rimg (نسخه‌های webp کوچک) حذف شده → تا ساخته‌شدنشان، عکس اصلی
   نمایش داده می‌شود (fallback داخل img.js). عملکرد سایت خراب نمی‌شود.

4) فایل‌های .gz و .br حذف شده → برای سرعت بیشتر بعد از npm install اجرا کنید:
       npm run precompress

5) دیتابیس کامل با همه محصولات و تنظیمات: data/netcorepro.db
   اجرا:  node dist/server.js   (پورت پیش‌فرض طبق .env / deploy/)
